# Security Policy

## Supported versions

Security fixes are made against the latest released version of Blueprint.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose
**Report a vulnerability** (GitHub private security advisories). Include what you found, how to
reproduce it and which version is affected.

You can expect an acknowledgement within a few days. Once a fix is ready it is released and the
advisory is published, crediting you if you wish.

Blueprint does no networking and stores no data, but it decodes untrusted JSON. Reports about
crashes, resource exhaustion or unsafe behaviour triggered by a crafted payload are in scope.
